# EON General Supply Company - Official Website

> Quality Parts, Reliable Service - Your trusted partner for industrial and automotive supply solutions across South Africa

## 🏢 About EON General Supply Company

EON General Supply Company is a leading B-BBEE Level 1 contributor and 100% youth, woman, and black-owned supplier of industrial and automotive parts in South Africa. We specialize in providing high-quality OEM and aftermarket parts, custom parts sourcing, bulk supply, and complete engine and radiator refurbishment services.

## 🌐 Website

A modern, fully responsive website built with HTML5, CSS3, and JavaScript featuring:

- Complete company information and services
- Interactive quote request system
- Comprehensive product and brand catalog
- Mobile-friendly responsive design
- Professional UI/UX design
- Form validation and user feedback
- Smooth animations and transitions

## 🚀 Quick Start

Simply open `index.html` in any modern web browser, or run a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Then visit: http://localhost:8000
```
